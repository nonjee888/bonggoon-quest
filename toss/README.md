# 토스 미니앱(앱인토스) 빌드

GitHub Pages 사이트(`index.html`)는 그대로 두고, 미니앱용 묶음만 따로 만들어요.

```sh
npm ci
npm run build:toss   # → dist/ + bonggoon-quest.ait
```

미니앱 번들에서만 달라지는 점 (`toss/entry.js`, `toss/build.mjs`):

- GoatCounter 유입이 `toss`로 집계돼요 (`?ref=kakao·qr·story`와 같은 자리).
- 공유 묶음(이미지 저장·인스타 스토리·카카오톡)과 인스타 링크는 숨겨요. 공유 링크가 github.io로 가는 것과 자사 채널 유도는 앱인토스 정책상 막혀 있어요. 공유는 토스 내비게이션 바의 ⋯ 메뉴로 해요.
- 입양 신청서는 `openURL`로 기기 브라우저에서 열려요.
- 핀치 줌을 막아요 (체크리스트 항목).
- 마지막 질문에 답하면 봉군이 산책 로딩(최대 3초)을 보여준 뒤 결과가 나와요.

## 오너가 콘솔에서 할 일 (순서대로)

1. 앱인토스 콘솔 가입 → 워크스페이스 만들기 (사업자 등록 없이 가능. 결제·토스 로그인·프로모션을 쓸 때만 필요)
2. 앱 등록: 앱 유형 **비게임**, 앱 이름(국문 / 영문 15자 이내 명사형), `appName`(한 번 정하면 못 바꿔요), 로고 600×600 PNG(봉군이 얼굴 OK, 사람 얼굴 X), 썸네일 1932×828, 세로 스크린샷 636×1048, 카테고리, 설명, '앱 내 기능' = 산책 궁합 테스트
   - `appName`이 `bonggoon-quest`가 아니면 `apps-in-toss.config.ts`의 `appName`만 바꿔 주세요.
3. 앱 정보 검토 요청 → 승인 대기
4. `npm run build:toss` → 콘솔 '출시하기'에 `bonggoon-quest.ait` 업로드 (또는 `npx ait deploy`. API 키는 오너가 직접 입력)
5. 콘솔 QR(`intoss-private://`)로 토스 앱에서 직접 테스트 (최소 1번 해야 검토 요청이 돼요)
6. 출시 검토 요청 → 승인되면 출시
